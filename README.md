# Monitor de Segurança de Rede

## Sobre o projeto

O Monitor de Segurança de Rede é um projeto acadêmico desenvolvido para demonstrar conceitos básicos de Redes de Computadores e Cybersecurity.

O sistema analisa eventos registrados em um arquivo de logs e identifica comportamentos potencialmente suspeitos.

## Objetivos

- Analisar eventos de segurança;
- Identificar atividades suspeitas;
- Monitorar eventos associados a endereços IP;
- Gerar alertas de segurança;
- Praticar Python;
- Aplicar Git e GitHub.

## Tecnologias

- Python 3
- Git
- GitHub
- Markdown

## Funcionamento

O sistema lê eventos armazenados em um arquivo de log.

Exemplo:

```text
2026-09-08 10:15:01 | 192.168.1.10 | LOGIN_SUCCESS
2026-09-08 10:15:05 | 192.168.1.50 | LOGIN_FAILED
