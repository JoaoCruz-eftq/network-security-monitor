# Relatório de Incidente

## Resumo

Durante a análise dos logs fictícios utilizados no projeto Monitor de Segurança de Rede, foi identificado um endereço IP com quantidade elevada de eventos suspeitos.

## IP analisado

192.168.1.50

## Eventos identificados

O endereço apresentou múltiplas ocorrências de:

- LOGIN_FAILED
- CONNECTION_DENIED

## Classificação

O comportamento foi classificado como atividade potencialmente suspeita.

## Recomendação

Em um ambiente real, o alerta poderia ser encaminhado para uma equipe de segurança para investigação adicional.

## Observação

Os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins acadêmicos.
